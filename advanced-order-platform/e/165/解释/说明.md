- v165 不替代 Java v164 approval gate input。
- v165 不声明 runtime gate approval 已存在。
- v165 不声明 Node-approved runtime window 或 correlated operator approval record 已存在。
- v165 不组装 complete cross-project runtime execution packet。
- v165 不启动或停止 Java / mini-kv。
- v165 不执行 runtime probe。
- v165 不读取 credential value 或 raw endpoint value。
- v165 不启用 active shard router、write routing、多进程分片或写命令。
