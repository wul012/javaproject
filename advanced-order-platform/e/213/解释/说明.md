# Java v213 v211 consumer handoff bundle historical compatibility

v213 为 v211 consumer handoff bundle 增加历史兼容守卫。

该测试确认 v211 bundle 不会被回填进 v208 endpoint catalog，也不会被写回 v179/v184 的旧 registry snapshot。它还确认 v211 bundle 的 requiredEvidence 不会因为 v212 freeze 出现而被反向修改。

当前 rolling registry 仍会发现 bundle endpoint，并保持 endpoint catalog -> consumer handoff bundle -> read-only evidence catalog 的顺序。
