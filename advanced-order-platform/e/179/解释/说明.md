# Java v179 read-only catalog handoff verification

This version adds a read-only verification endpoint for the Java v175 catalog and Java v177 handoff.

## What Changed

- Added `OpsShardReadinessReadOnlyEvidenceCatalogHandoffVerificationService`.
- Added `OpsShardReadinessReadOnlyEvidenceCatalogHandoffVerificationResponse`.
- Added `GET /api/v1/ops/shard-readiness/read-only-evidence-catalog-handoff-verification`.
- Added the v179 fixture and evidence archive.
- Added service and integration tests.

## Why

The v175 catalog is frozen at 20 live endpoints and 20 fixture endpoints. The current global registry can grow beyond that. This version proves both facts are true at the same time.

## Boundaries Held

- No root readiness schema change.
- No write routing.
- No active shard router.
- No credential or raw endpoint reads.
- No managed audit connection.
- No Java or mini-kv process start/stop.
- No deployment or rollback path.
