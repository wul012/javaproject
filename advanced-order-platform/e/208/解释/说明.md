# Java v208 shard readiness v1 contract endpoint catalog

v208 新增 `/api/v1/ops/shard-readiness/v1-contract-endpoint-catalog`，用于集中暴露六个 v1 contract artifact 的 live endpoint、fixture endpoint、evidence path 和 receipt。

该 endpoint 是只读 catalog，不启动 Java/mini-kv，不解析 raw endpoint，不读取凭据值，也不触发任何写路由或运行时执行。

本版同步更新了 `OpsShardReadinessV1ContractEndpointPairs`、`OpsShardReadinessEvidenceEndpoints` 和 `OpsEvidenceServiceTests` 中的探针列表，确保新 catalog 能被 Java evidence registry 和 ops evidence additional probes 发现。
