# Java v230 v1 contract consumer readiness handoff evidence chain

v230 把 v225 readiness handoff 的证据链合成后做闭合验证。

链条由三段组成：

- v215-v219：Java v220 digest 已经收进去的 checklist 输入证据；
- v221-v224：围绕 Java v220 digest 的 snapshot、历史兼容、完整性和 completion guard；
- v225：readiness handoff 自己的 evidence path。

这三段合起来是 10 条。v226-v230 是对 v225 handoff 的后续验证，不属于 v225 handoff 发布时的原始链条，所以测试明确要求它们不出现在 frozen v225 handoff chain 中。

本版还验证 `handoffChecks` 中的 count 与实际列表大小一致，避免以后只改列表、不改检查项，或者反过来只改检查项、不改列表。
