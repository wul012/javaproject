# Java v171 runtime execution route group split 说明

本版是维护性拆分，不新增 evidence gate，也不改变任何 API path 或响应结构。

## 做了什么

- 从 `OpsShardReadinessController` 中拆出 runtime execution 相关 9 个接口。
- 新增 `OpsShardReadinessRuntimeExecutionController`，统一挂在 `/api/v1/ops/shard-readiness` 下。
- 保留 v162-v170 既有 runtime execution endpoint 的完整路径。
- 对齐 Node v410 的 route group split 思路，避免中央控制器继续膨胀。

## 明确没有做什么

- 没有新增 runtime approval / pass-evidence gate。
- 没有启动或停止 Java / mini-kv 服务。
- 没有连接 managed audit。
- 没有读取 credential 或 raw endpoint。
- 没有打开写路径或 active shard 路由。

## 验证口径

- 编译必须通过。
- runtime execution 相关集成测试必须继续命中原路径。
- 全量 `mvn -q test` 必须通过。
- 本目录保留 JSON、HTML、截图和浏览器快照证据。
