# Java v236 v1 contract consumer readiness handoff receipt uniqueness

v236 验证 consumer readiness 链上的 receipt 和 evidence path 不重复。

这条链包括：

- v211 consumer handoff bundle；
- v215 consumer verification checklist；
- v220 consumer evidence digest；
- v225 consumer readiness handoff。

本版确保每层都有独立 receipt 和独立 evidence path。这样下游排查证据时不会遇到两个版本共享同一个 receipt，或者两个版本写到同一个 evidence path 的问题。
