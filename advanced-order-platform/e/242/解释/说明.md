# Java v242 v1 contract consumer readiness handoff catalog continuity

v242 验证 v241 新增的 post-handoff catalog 是否连续、唯一、并且路径版本自洽。

本版检查：
- catalog 的版本必须正好是 v226-v242；
- receipt record 不重复；
- evidence path 不重复；
- 每条 path 都必须落在自己的版本目录里；
- 每条 path 都必须以自己的 `-v<version>.json` 结尾。

这能防止后续追加 evidence 时出现三类常见问题：
- 版本号跳过；
- 两个版本误用同一个 evidence path；
- 文件放在一个版本目录里，但文件名或常量指向另一个版本。

v242 仍然只做只读验证，不新增 endpoint，也不改变 v225 handoff payload。
