# Java v175 read-only evidence catalog

This version adds a read-only evidence catalog for Java shard-readiness consumers.

## What Changed

- Added `OpsShardReadinessReadOnlyEvidenceCatalogService`.
- Added `OpsShardReadinessReadOnlyEvidenceCatalogResponse`.
- Added `GET /api/v1/ops/shard-readiness/read-only-evidence-catalog`.
- Added `/contracts/java-shard-readiness-read-only-evidence-catalog-v175.fixture.json`.
- Cataloged 20 live shard-readiness endpoints and 20 fixture endpoints.
- Linked the v174 echo receipt and the v170 runtime pass-evidence closeout receipt.
- Archived JSON, HTML, browser snapshot, screenshot, and tests for v175.

## Boundaries Held

- The v153 root readiness schema is unchanged.
- Write routing remains closed.
- The active shard router remains disabled.
- Credential values and raw endpoints are not read.
- Managed audit is not connected.
- Java and mini-kv are not started or stopped by this endpoint.
- Deployment and rollback remain out of scope.

## Verification

- Compile must pass.
- Catalog service and integration tests must pass.
- Evidence endpoint lists must include the new live and fixture endpoints.
- JSON fixture and evidence files must parse.
- Browser snapshot and screenshot must render the v175 archive page.
