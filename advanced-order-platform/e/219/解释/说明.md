# Java v219 v1 contract consumer route inventory

v219 adds `OpsShardReadinessV1ContractRouteInventoryTests`.

The inventory test compares:

- GET mappings declared on `OpsShardReadinessV1ContractController`;
- shared `OpsShardReadinessRoutePaths` constants;
- live/fixture endpoint pairs from `OpsShardReadinessV1ContractEndpointPairs`.

This prevents later v1 contract work from adding a controller route without registering it in endpoint pairs, or from mixing read-only catalog/evidence-index routes into the v1 contract group.
