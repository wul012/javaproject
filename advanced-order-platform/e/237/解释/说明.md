# Java v237 v1 contract consumer readiness handoff node consumer boundary

v237 验证 Node 消费者边界。

这里的结论是：Node 可以消费 Java readiness evidence，但不能因此获得操作 Java 或 mini-kv 的能力。

本版明确验证：

- checklist、digest、handoff 都不允许 Node 启停 Java 或 mini-kv；
- handoff 不启动 Java service，也不启动 mini-kv；
- handoff 不允许 write routing 或 active shard router；
- handoff 不读取 credential value，不解析 raw endpoint，不建立 managed audit connection；
- handoff 不允许 deployment 或 rollback；
- handoff checks 和 blocked operations 都显式暴露 Node no-start/no-stop 规则。
