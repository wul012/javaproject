# Java v247 readiness handoff blocked operation catalog

v247 把 consumer readiness 链路中的 blocked operations 单独作为 catalog 验证。

测试确认 checklist、evidence digest、readiness handoff 三层都暴露同一组禁止操作：
- write routing；
- active shard router；
- credential value read；
- raw endpoint parse；
- managed audit connection；
- deployment or rollback；
- Node 启停 Java 或 mini-kv。

这版仍然只做只读验证，不新增 endpoint，不打开执行能力。
