# Java v181 route path constants

本版把 shard-readiness evidence 相关 controller/service 的路径字面量收敛到 `OpsShardReadinessRoutePaths`，不新增接口、不改变现有路径。

## 变更

- 新增 `OpsShardReadinessRoutePaths`，集中定义 base path 和 6 个 evidence route。
- `OpsShardReadinessEvidenceController`、`OpsShardReadinessReadOnlyEvidenceController` 改用共享 route constants。
- 6 个 evidence service 的 `ENDPOINT` 改为 `BASE_PATH + route constant`。
- 新增 `OpsShardReadinessRoutePathsTests`，锁住 route 常量与 service endpoint 的对应关系。

## 边界

- endpoint registry 仍为 22 live / 22 fixture。
- 现有 6 个 HTTP 路径保持原样。
- 未新增 write routing、active shard router、credential value、raw endpoint parse、managed audit connection、deployment / rollback。
- Node 仍不得自动启动或停止 Java / mini-kv。
