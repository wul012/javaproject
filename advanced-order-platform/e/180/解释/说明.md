# Java v180 read-only evidence controller split

本版只做 controller 责任拆分，不新增接口、不修改现有路径、不打开执行能力。

## 变更

- 新增 `OpsShardReadinessReadOnlyEvidenceController`，承接 read-only catalog、handoff、handoff verification 三个只读入口。
- 收窄 `OpsShardReadinessEvidenceController`，只保留 evidence index、verification、handoff 三个普通证据入口。
- 新增 `OpsShardReadinessReadOnlyEvidenceControllerSplitTests`，固定 read-only catalog 路由由专用 controller 承接。

## 边界

- endpoint registry 仍为 22 live / 22 fixture。
- 未新增 write routing、active shard router、credential value、raw endpoint parse、managed audit connection、deployment / rollback。
- Node 仍不得自动启动或停止 Java / mini-kv。

- full: `mvn -q test`
