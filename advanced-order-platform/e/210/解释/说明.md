# Java v210 v208 endpoint catalog historical compatibility

v210 为 v208 endpoint catalog 增加独立历史兼容守卫。

该测试确认 v208 catalog 只列出六个历史 v1 contract artifact，不把 endpoint catalog 自身塞进自己的历史 artifact 列表，也不把 read-only evidence catalog 混进 v1 contract artifact 范围。

同时测试确认 v179、v184 的旧 registry snapshot 不会被回填 v208 catalog endpoint；当前 rolling registry 则会把 v208 catalog 放在 consumer-probe-plan 之后、read-only evidence catalog 之前。
