# Java v229 v1 contract consumer readiness handoff route inventory

v229 验证 readiness handoff 的路由清单。

这版关注的是“同一个合同是否在所有入口清单中保持一致”：

- v1 endpoint-pair registry 仍然是 11 个 pair；
- readiness handoff 是当前 v1 consumer 链末尾的 pair；
- route path 仍然是 `/v1-contract-consumer-readiness-handoff`；
- live probe 和 fixture probe 都有 `GET` 形式的 readiness handoff entry；
- v225 static fixture 能在 classpath 的 `static/contracts` 下被发现。

这类 guard 的价值在于防止未来改路由、移动 fixture 或调整 endpoint pair 顺序时，只改了一处而漏掉其他清单。
本版没有打开运行时写能力，也没有新增 endpoint。
