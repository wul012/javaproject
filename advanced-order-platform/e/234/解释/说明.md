# Java v234 v1 contract consumer readiness handoff boundary matrix

v234 把 consumer verification checklist、consumer evidence digest、consumer readiness handoff 三层放进同一张边界矩阵。

这版验证它们都满足：

- `readOnly=true`；
- `executionAllowed=false`；
- `shardEnabled=false`；
- probe 只允许 GET；
- upstream actions 不允许；
- 不启动 Java；
- 不启动 mini-kv；
- 不允许 write routing；
- 不允许 active shard router；
- 不读取 credential value；
- 不解析 raw endpoint；
- 不建立 managed audit connection；
- 不允许 deployment/rollback；
- 不允许 Node 启停 Java 或 mini-kv；
- blocked operations 列表完全一致。

这相当于把 v215、v220、v225 三个 consumer 层的只读边界合并成一个可测试矩阵，后续任何一层边界漂移都会被发现。
