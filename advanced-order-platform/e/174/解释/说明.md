# Java v174 shard readiness echo 说明

本版新增独立只读 echo，不修改 v153 `/api/v1/ops/shard-readiness` 的冻结 schema。

## 做了什么

- 新增 `OpsShardReadinessEchoService` 和 `OpsShardReadinessEchoResponse`。
- 新增 `GET /api/v1/ops/shard-readiness/echo`。
- 汇总 v153 readiness、v154 hardening、v155 evidence index、v157 evidence handoff。
- 把 v171-v173 的 controller split 结果作为可消费证据写入 echo。
- 新增静态 fixture、证据 JSON、HTML、截图和浏览器快照归档。

## 明确没有做什么

- 没有改变 v153 root readiness schema。
- 没有打开 write routing。
- 没有启用 active shard router。
- 没有读取 credential value 或 raw endpoint。
- 没有连接 managed audit。
- 没有部署、回滚、启动或停止 Java / mini-kv。

## 验证口径

- 编译必须通过。
- echo 服务测试和接口测试必须通过。
- evidence endpoint 列表必须纳入 echo live/fixture endpoint。
- 全量 `mvn -q test` 必须通过。
