# Java v244 v1 contract consumer readiness handoff catalog JSON boundary

v244 开始读取 evidence JSON 本身。

前几版确认了 catalog 连续、路径唯一、归档文件存在。
但文件存在不等于字段可信，所以本版用 `ObjectMapper` 逐个解析 catalog 中的 evidence JSON。

测试要求每条 receipt 满足：
- `version` 等于 catalog 中的 Java version；
- `status` 是 `passed`；
- `readOnly` 是 `true`；
- `executionAllowed` 是 `false`。

这使得 post-handoff evidence 不只是“有文件”，还必须在字段层面继续保持只读边界。
后续新增 receipt 时，这个测试会自动覆盖新 JSON。
