# Java v215 v1 contract consumer verification checklist

v215 adds `OpsShardReadinessV1ContractConsumerVerificationChecklistService`.

This endpoint is still read-only. It points to the v211 consumer handoff bundle and lists the evidence that a Node consumer must confirm before consuming that bundle:

- v208 endpoint catalog evidence.
- v211 consumer handoff bundle evidence.
- v212 bundle snapshot freeze evidence.
- v213 bundle historical compatibility evidence.
- v214 bundle integrity evidence.

The endpoint does not enable write routing, an active shard router, credential value reads, raw endpoint parsing, managed audit connections, deployment or rollback, or Node process control over Java / mini-kv.
