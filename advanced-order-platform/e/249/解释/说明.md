# Java v249 readiness handoff credential/raw endpoint boundary

v249 专门验证 credential value 和 raw endpoint 的边界。

readiness handoff 需要告诉下游这些操作被禁止，但 Java 自身也不能在这个只读交接中读取 credential value 或解析 raw endpoint。

测试确认 checklist、digest、handoff 三层：
- `credentialValueRead` 都是 false；
- `rawEndpointParsed` 都是 false；
- blocked operations 中仍然包含 `credential-value-read` 和 `raw-endpoint-parse`。
