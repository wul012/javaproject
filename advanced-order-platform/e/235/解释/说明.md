# Java v235 v1 contract consumer readiness handoff endpoint adjacency

v235 验证 readiness handoff 在 endpoint 链中的邻接关系。

这版关注两个顺序：

- 在 v1 contract endpoint-pair registry 中，readiness handoff 必须紧跟 evidence digest；
- 在整体 rolling evidence registry 中，catalog、bundle、checklist、digest、readiness handoff、read-only catalog 必须保持顺序。

这能防止后续新增 endpoint 时，把 readiness handoff 插错位置，导致下游消费者无法按“先 digest、再 handoff、最后进入 read-only catalog”的顺序消费。
