# Java v232 v1 contract consumer readiness handoff controller mapping

v232 验证 controller 层的 readiness handoff 映射。

前几个版本已经验证 service、snapshot、registry 和 OpsEvidence 清单。本版把焦点放在 controller：

- `consumerReadinessHandoff()` 方法返回 readiness handoff response；
- `@GetMapping` 使用 readiness handoff route 常量；
- controller 构造函数中 readiness handoff service 紧跟在 evidence digest service 之后；
- controller split 测试仍然识别这个 route；
- MockMvc integration 仍然能访问 live endpoint 和 static fixture。

这能防止未来拆 controller 或调整构造函数时漏掉 readiness handoff 注入，导致应用启动或 endpoint 映射异常。
