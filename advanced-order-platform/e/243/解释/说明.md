# Java v243 v1 contract consumer readiness handoff catalog archive presence

v243 把 v241-v242 的 catalog 进一步变成可审计归档。

它不只检查 catalog 里有没有 evidence path，还检查每个 catalog receipt 是否真的有完整归档文件：
- evidence JSON；
- browser snapshot；
- HTML evidence 页面；
- PNG 截图；
- 中文说明文档。

测试通过 catalog 自动推导文件路径。
这样未来追加版本时，只要把 receipt 加入 catalog，就会自动要求对应归档文件存在。

这能防止“常量已经写了，但证据目录没有落文件”的情况。
本版仍然只读，不新增 endpoint，也不改变 v225 readiness handoff payload。
