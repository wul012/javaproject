# Java v182 paired endpoint registry

本版把 `OpsShardReadinessEvidenceEndpoints` 的 live/fixture 双列表改为成对 registry，再派生 live、fixture 和 probe 列表。外部路径和顺序不变。

## 变更

- 新增内部 `EndpointPair(liveEndpoint, fixtureEndpoint)`。
- `endpointPairs()` 作为单一源维护 22 对 live/fixture endpoint。
- `liveEndpoints()`、`fixtureEndpoints()` 从 pair 派生，避免后续一边加了另一边漏加或错位。
- `OpsShardReadinessEvidenceEndpointsTests` 增加 pair 顺序和值检查。

## 边界

- endpoint registry 仍为 22 live / 22 fixture / 22 pair。
- 现有路径和顺序保持不变。
- 未新增 write routing、active shard router、credential value、raw endpoint parse、managed audit connection、deployment / rollback。
- Node 仍不得自动启动或停止 Java / mini-kv。

- full: `mvn -q test`
