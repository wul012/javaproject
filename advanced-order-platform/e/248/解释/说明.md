# Java v248 readiness handoff GET-only probe boundary

v248 验证 consumer readiness 链路只允许 GET 探针。

测试覆盖：
- checklist、digest、handoff 的 `probesAreGetOnly` 都是 true；
- 三层的 `upstreamActionsAllowed` 都是 false；
- live probe endpoints 都以 `GET ` 开头；
- fixture probe endpoints 也都以 `GET ` 开头。

这版防止未来把 POST/PUT/PATCH/DELETE 这类写或执行语义混进 readiness handoff 消费链。
