# Java v211 shard readiness v1 contract consumer handoff bundle

v211 新增 `/api/v1/ops/shard-readiness/v1-contract-consumer-handoff-bundle`。

该 bundle 以 v208 endpoint catalog 为基础，串联 v209 snapshot freeze 和 v210 historical compatibility evidence，给消费方一个更完整的只读交接入口。

它不执行探针、不启动服务、不读取凭据、不解析 raw endpoint，只声明 GET-only read targets、fixture read targets、required evidence 和 handoff evidence。
