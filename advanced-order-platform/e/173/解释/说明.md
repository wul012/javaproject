# Java v173 evidence route group split 说明

本版完成 shard-readiness controller 的最后一段维护性拆分，不新增 evidence gate，不改变 API path 或响应结构。

## 做了什么

- 新增 `OpsShardReadinessEvidenceController`。
- 从 `OpsShardReadinessController` 拆出 evidence-index、evidence-verification、evidence-handoff 3 个 endpoint。
- `OpsShardReadinessController` 现在只保留基础 readiness 和 hardening endpoint。
- 对齐 Node v413 的 route group split 思路，避免中央控制器重新膨胀。

## 明确没有做什么

- 没有新增 evidence gate。
- 没有启动或停止 Java / mini-kv。
- 没有连接 managed audit。
- 没有读取 credential 或 raw endpoint。
- 没有打开写路径或 active shard 路由。

## 验证口径

- 编译必须通过。
- evidence 相关集成测试必须继续命中原路径。
- 全量 `mvn -q test` 必须通过。
- 本目录保留 JSON、HTML、截图和浏览器快照证据。
