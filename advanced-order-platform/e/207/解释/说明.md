# Java v207 shard readiness v1 contract controller split

v207 将 v1 contract 的六个只读端点从 `OpsShardReadinessController` 拆到 `OpsShardReadinessV1ContractController`，主 controller 只保留 readiness、hardening、echo 三类基础读端点。

本版同时把 v1 contract 路由补进 `OpsShardReadinessRoutePaths`，并让服务端点常量由共享 route constant 组合生成。这样后续继续扩展 v1 contract evidence 时，不会继续拉大主 controller，也降低路径字符串分散带来的维护风险。

边界保持不变：没有打开写路由、active shard router、凭据值读取、raw endpoint 解析、managed audit connection、deployment/rollback 或 Node 启停 Java/mini-kv。
