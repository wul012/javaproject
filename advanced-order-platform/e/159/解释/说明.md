Node v383 已验证 Node v382 对 Java v158 与 mini-kv v149 boundary handoff 的归档回放。Node 下一步需要新的冻结证据，或者明确 live-read gate 服务启停计划。Java v159 补上 Java 侧只读服务生命周期计划：声明 owner、端口/baseUrl、GET smoke、fail-closed 与 cleanup 责任，但不启动服务、不执行 live read。

## 服务生命周期边界

- Node 不能仅凭本计划启动 Java。
- Java operator 在 live-read window 前启动服务。
- Java 端口或 baseUrl 必须由 operator 明确声明。
- Node 只执行 GET smoke targets。
- 缺 owner、端口/baseUrl、cleanup owner 或 smoke 失败都 fail closed。

## 边界

- 不修改 Java v153-v158 输出。
- 不启动或停止 Java / mini-kv。
- 不读取 credential value 或 raw endpoint value。
- 不启用 active shard router、write routing、多进程分片或写命令。
