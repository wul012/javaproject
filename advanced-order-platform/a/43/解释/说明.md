# 第四十三版：replay execution-contract 稳定样本

## 计划依据

本版推进前重新读取最新计划：

```text
D:\nodeproj\orderops-node\docs\plans\v73-post-execution-contract-diagnostics-roadmap.md
```

计划对 Java v43 的目标是：

```text
为 replay-execution-contract 增加稳定 fixture / sample response。
样本字段要覆盖 contractVersion、contractDigest、approvalDigest、replayEligibilityDigest、
replayPreconditionsSatisfied、digestVerificationMode、expectedSideEffects。
```

按“每版工作量合适”的规则，本轮只推进 Java v43，不同时修改 Node 或 mini-kv。

## 合理性判断

计划合理，原因：

```text
1. Node v73 已有 execution-contract diagnostics，下一步需要稳定样本降低 mock 漂移。
2. Java v43 只增加静态 sample JSON 和测试，不新增写接口。
3. 样本随应用打包，Node 后续可以读取真实 Java 项目提供的格式参考。
4. 不修改真实 replay-execution-contract 算法，不影响生产运行。
```

因此本版直接执行，没有暂停等待确认。
