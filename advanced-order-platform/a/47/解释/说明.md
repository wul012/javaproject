# 第四十七版：replay evidence index 说明接口

## 计划依据

本版推进前只读查看最新计划：

```text
D:\nodeproj\orderops-node\docs\plans\v99-production-readiness-v2-roadmap.md
```

计划里对 Java v47 的目标是：

```text
补 replay audit evidence 的说明 endpoint 或 README sample index。
```

## 合理性判断

计划合理：

```text
1. Java v43-v44 已有 execution-contract approved/blocked 样本。
2. Java v46 已有 replay audit approved/blocked 样本。
3. 后续控制面需要一个稳定入口知道 Java 到底提供了哪些证据。
4. 本版只做 Java，不修改 Node，不修改 mini-kv。
```

因此本版选择做说明 endpoint，而不是只补 README。

## 本版目标

新增只读接口：

```text
GET /api/v1/failed-events/replay-evidence-index
```

核心语义：

```text
readOnly=true
executionAllowed=false
evidenceVersion=failed-event-replay-evidence-index.v1
liveEvidenceEndpoints=Java 当前可读的 replay evidence endpoint
staticEvidenceSamples=Java 当前随包提供的 replay evidence 样本
auditIdentityFields=审计追溯必须关注的身份字段
executionSafetyRules=真实 replay 前不可绕过的安全规则
```

## 一句话总结

v47 把 Java 当前的 replay live evidence、静态样本、审计身份字段和执行安全规则聚合成只读说明接口，给后续生产 readiness 汇总提供稳定上游目录。
