## Clearance status

All 291 existing non-compliant walkthrough files have been marked with:

```text
legacy-nonstandard-walkthrough
```

That marker is a clearance label, not a pass. It means the file is preserved for historical traceability, but it is not counted as a standard code walkthrough. Rewritten files must remove the marker and adopt the Node v103-style sections in `代码讲解记录_写作规范.md`.

## Rewrite rule

When a file is rewritten, use `代码讲解记录_写作规范.md` and keep the filename stable unless the file is being moved into a version-range folder.

Do not bulk-pad a historical note with empty headings. If the code surface cannot be reconstructed from repository evidence, either leave the version without a walkthrough or mark the missing section explicitly with the reason.
