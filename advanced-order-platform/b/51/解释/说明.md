
```text

```

## Docker 判断

本版只新增静态 JSON 样本和只读 endpoint 引用，不改 PostgreSQL migration、RabbitMQ、Outbox 发布、消息消费或交易状态机。

因此本版必要验证不启动 Docker；Docker/Testcontainers 回归不属于本次改动的直接风险面。

## 边界

本版不做：

```text
不执行订单写操作
不执行 Java replay POST
不发布 RabbitMQ replay 消息
不修改数据库结构
不修改 Node
不修改 mini-kv
不把字段说明样本伪装成 live upstream pass
```

v51 给 Java ops evidence 补了一份字段说明样本，让 Node 后续 release evidence review 能解释 service、healthProbe、readOnlyWindow 和执行边界字段，同时继续保持只读和非生产放行边界。
