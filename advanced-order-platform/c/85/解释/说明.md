# v85 运行说明

## 1. 版本目标

Java v85 继续做 release approval rehearsal 的 contract-preserving refactor，不新增业务 receipt，也不改变 Node 可消费的响应契约。
目标是回答本轮质量问题：`OpsEvidenceService` 不能继续膨胀，主文件要从 2600 行级别压到 2000 以内，并尽量靠近 1500 行。

## 2. 拆分结果

新增：

```java
ReleaseApprovalRehearsalResponseBuilder
ReleaseApprovalRehearsalHintBuilder
ReleaseApprovalRehearsalHandoffHintBuilder
ReleaseApprovalRehearsalFailureTaxonomyBuilder
```

职责划分：

- `ReleaseApprovalRehearsalResponseBuilder` 负责 header 归一化、hint/receipt 串联、verification hint 接入、release inputs/live signals/blockers 组装。
- `ReleaseApprovalRehearsalHintBuilder` 负责 request context、operator window、CI evidence、artifact retention、live readiness 等早期只读 hint。
- `ReleaseApprovalRehearsalHandoffHintBuilder` 负责 audit persistence handoff、approval record handoff 和 approval handoff verification marker。
- `ReleaseApprovalRehearsalFailureTaxonomyBuilder` 负责 release approval rehearsal 的 failure taxonomy。
