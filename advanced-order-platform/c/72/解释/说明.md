# v72 运行调试说明

## 版本目标

本版按最新计划 `D:\nodeproj\orderops-node\docs\plans\v200-post-ci-artifact-manifest-roadmap.md` 推进 Java v72：为 release approval rehearsal 增加只读 `artifactRetentionHint`，回显 Node v202 CI artifact upload dry-run contract 的 artifact name、artifact root、retention days、upload mode 和 digest。

## 主要改动

- `ReleaseApprovalRehearsalResponse` 新增 `artifactRetentionHint`。
- `OpsOverviewController` 为 `/api/v1/ops/release-approval-rehearsal` 新增 6 个可选 `x-orderops-ci-*` retention/upload contract header。
- `OpsEvidenceService` 增加 `rehearsalArtifactRetentionHint(...)`，引用 Java 既有 `releaseAuditRetentionFixture`，并把 schema 升级到 `java-release-approval-rehearsal-response-schema.v6`。
- 测试覆盖缺省 header、完整 header、warning digest 稳定性和 HTTP JSON 输出。
- README 和代码讲解补充 v72 说明。

## 关键边界

- Java 不上传 CI artifact。
- Java 不访问 GitHub artifact 或 token。
- Java 不写 audit export。
- Java 不创建 approval decision，不写 approval ledger。
- Java 不触发 deployment、rollback 或 rollback SQL。
- `artifactRetentionHint.nodeMayTreatAsRetentionAuthorization=false`，后续仍需 Node v203 gate 汇总三项目证据。
