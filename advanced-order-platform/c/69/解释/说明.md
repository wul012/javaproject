## 合理性判断

合理。v66-v68 已经分别补齐 rehearsal 聚合、请求上下文和失败分类；v69 在同一个只读响应中补 schema version、warning digest 和 no-ledger-write proof，能服务 Node 后续导入人工窗口结果和 production readiness checkpoint。版本工作量适中，没有新增写接口，没有接入真实 IdP，也没有改变订单交易语义。

## 本版目标

- `ReleaseApprovalRehearsalResponse` 新增 `verificationHint`。
- `verificationHint.hintVersion` 固定为 `java-release-approval-rehearsal-verification-hint.v1`。
- `verificationHint.responseSchemaVersion` 固定为 `java-release-approval-rehearsal-response-schema.v3`。
- `verificationHint.warningDigest` 使用 `sha256:` 摘要，覆盖 context warnings、failure taxonomy warnings 和 no-ledger 边界字段。
- `verificationHint.noLedgerWriteProof` 固定为 `NO_LEDGER_WRITE_PROOF_BY_RESPONSE_FIELDS`。
- `verificationHint.noLedgerWriteProved=true`，并明确 `nodeMayTreatAsProductionAuthorization=false`。
- 补服务层测试与 MVC 集成测试。
- 补 README、代码讲解和运行归档。

## 代码改动

- `ReleaseApprovalRehearsalResponse` 增加 `RehearsalVerificationHint` record。
- `OpsEvidenceService` 增加 verification hint 和 response schema 两个版本常量。
- `OpsEvidenceService.releaseApprovalRehearsal(...)` 将 `requestContext`、`failureTaxonomy`、`executionBoundaries` 作为局部对象统一组装。
- `OpsEvidenceService` 增加 `releaseApprovalVerificationHint(...)`、`warningDigest(...)`、`digest(...)`、`line(...)`、`value(...)`。
- `OpsEvidenceServiceTests` 验证 hint 字段、warning digest 前缀、digest 稳定性、no-ledger proof 和非生产授权边界。
- `OpsOverviewIntegrationTests` 验证 HTTP JSON 中 `verificationHint.*` 字段。
- `README.md` 和 `代码讲解记录_生产雏形阶段/73-version-69-release-approval-verification-hint.md` 补说明。
