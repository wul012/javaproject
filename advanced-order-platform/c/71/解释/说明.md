# v71 运行调试说明

## 版本目标

本版依照 `D:\nodeproj\orderops-node\docs\plans\v200-post-ci-artifact-manifest-roadmap.md` 的 Java v71 建议推进：为 release approval rehearsal 增加只读 `ciEvidenceHint`，让 Node v201 后续可以校验 Node v200 `real-read-window-ci-archive-artifact-manifest.v1` 的 manifest 摘要字段。

本版不连接真实 CI artifact store，不上传 GitHub artifact，不读取 GitHub secret，不写 approval ledger，不创建 approval decision，不打开生产窗口。

## 主要改动

- `ReleaseApprovalRehearsalResponse` 新增 `RehearsalCiEvidenceHint`。
- `OpsOverviewController` 增加 5 个可选只读 header：
  - `x-orderops-ci-manifest-version`
  - `x-orderops-ci-manifest-digest`
  - `x-orderops-ci-manifest-endpoint`
  - `x-orderops-ci-artifact-record-count`
  - `x-orderops-ci-approval-correlation-id`
- `OpsEvidenceService` 生成 `ciEvidenceHint`，并把 response schema 提升到 `java-release-approval-rehearsal-response-schema.v5`。
- `verificationHint.warningDigestInputs` 增加 `ciEvidenceEchoWarnings`。
- `verificationHint.proofClaims` 增加 CI artifact / GitHub artifact / production window 的禁止性证明。
- `README.md` 补 v71 调用示例和字段解释。
- `AGENTS.md` 更新为完成版本后默认 commit、tag、push，除非用户要求只保留本地。
