# Java v60 开发运行调试记录：production deployment runbook contract

## 版本目标

依据 `D:\nodeproj\orderops-node\docs\plans\v169-post-production-environment-preflight-roadmap.md`，本版推进 Java v60：

```text
production deployment runbook contract
```

目标是把生产部署窗口 owner、rollback approver、database migration direction 和 secret source confirmation 固化成只读 runbook contract。它服务后续 Node v170 deployment evidence intake gate。

## 本版边界

本版明确不做：

```text
不执行 Java 部署
不执行 Java rollback
不执行 rollback SQL
不连接生产数据库
不读取 production secret value
不修改 Java 运行配置
不授权 Node 触发部署或回退
```

```text

contractMode=READ_ONLY_DEPLOYMENT_RUNBOOK_CONTRACT
deploymentWindowOwner=release-window-owner

changesOrderTransactionSemantics=false
```
