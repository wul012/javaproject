# 开发运行调试 v64：release operator signoff fixture

## 本版目标

按最新计划 `v179-post-pre-approval-roadmap.md` 推进 Java v64：补 Java release operator signoff fixture，供后续 Node v180 approval decision prerequisite gate 只读消费。

本版工作量控制在一个小闭环内：新增动态 evidence 字段、静态 contract、相关证据链引用、测试与文档归档；不扩大到真实 approval decision、approval ledger、部署、回滚或 SQL。

## 改动范围

- 新增动态 evidence 字段 `releaseOperatorSignoffFixture`。
- 新增静态 contract：`/contracts/release-operator-signoff.fixture.json`。
- 将新 fixture 接入 release verification manifest、release bundle manifest、deployment rollback evidence、release handoff checklist、release audit retention、rollback approval handoff、production deployment runbook、ops read-only evidence、field guide。
- 补充 `OpsEvidenceServiceTests` 与 `OpsOverviewIntegrationTests`，验证动态字段、静态 endpoint、signoff placeholder、approval decision 禁止边界和 no-secret 边界。
- 补充 README 与代码讲解记录。
