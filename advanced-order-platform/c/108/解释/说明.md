# Java v108 运行说明：echo marker support 优化

## 计划依据

本版仍依据当前有效计划：

```text
D:\nodeproj\orderops-node\docs\plans\v263-post-disabled-resolver-echo-roadmap.md
```

v108 不新增新的业务 echo marker，而是对 v104-v107 的 echo marker 重复形态做小型 support 优化，先收口 warning / proof / verification 的公共样板。

## 合理性判断

合理。前一版已经把 test-only shell contract 落地，继续堆新 marker 只会让风格再膨胀。v108 先把重复的 warning 条件、warning 行和 verification 聚合整理出来，比再开一个新的业务版本更稳。

不合理的部分没有做：没有改 JSON 契约，没有改 schema version，没有改字段名，没有碰真实 resolver、secret provider、credential value、raw endpoint、外部请求、managed-audit connection、SQL、ledger 或 auto-start。

## 本版做了什么

新增轻量 support：

```text
ReleaseApprovalEchoMarkerSupport
```

用途只有三类：

```text
1. 统一 warning input name 包装
2. 统一 warning line 包装
3. 统一条件 warning 收集
```

它被以下 builder 复用：

```text
ReleaseApprovalManagedAuditSandboxEndpointHandlePreflightEchoMarkerBuilder
ReleaseApprovalManagedAuditSandboxEndpointCredentialResolverDecisionEchoMarkerBuilder
ReleaseApprovalManagedAuditSandboxEndpointCredentialResolverDisabledPrecheckEchoMarkerBuilder
ReleaseApprovalManagedAuditSandboxEndpointCredentialResolverTestOnlyShellEchoMarkerBuilder
```

## 本版目标

不是扩功能，而是把同一种重复收起来：

```text
markerWarnings = ArrayList + if add + List.copyOf
warningDigestWarningInputNames = 单项 List.of
warningDigestWarningLines = 单项 digest line
```

这些被 support 收敛后，四个 echo marker builder 的意图更集中，后续再继续做 v109 也不容易把重复再铺回去。
