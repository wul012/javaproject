# v78 运行说明

## 1. 版本目标

Java v78 在 `/api/v1/ops/release-approval-rehearsal` 上继续扩展只读合同，新增 `managedAuditProductionAdapterPrerequisiteReceipt`。它承接 Node v216 的 managed-audit dry-run adapter archive verification，并把 Node v217 production-hardening readiness gate 需要的前置条件、禁止操作边界和读取证据一次性公开出来。

```text
Java v77 managedAuditAdapterBoundaryReceipt
 -> Node v216 managed-audit dry-run adapter archive verification
 -> Java v78 managedAuditProductionAdapterPrerequisiteReceipt
 -> Node v217 production-hardening readiness gate
```

## 2. 新增字段

`ReleaseApprovalRehearsalResponse` 顶层新增：

```java
RehearsalManagedAuditProductionAdapterPrerequisiteReceipt managedAuditProductionAdapterPrerequisiteReceipt
```

这个 receipt 主要分四组信息：

```text
receiptVersion / sourceManagedAuditAdapterBoundary*
 -> Java v78 receipt 自身版本，以及它消费的 Java v77 boundary receipt schema

consumedByNodeArchiveVerification*
 -> Node v216 archive verification profile/state/endpoint

nextNodeGate*
 -> Node v217 production-hardening readiness gate 版本与 profile

nodeV217* / java*
 -> 明确仍然禁止真实 managed audit、approval decision、approval ledger、SQL、deployment、rollback、restore
```

## 3. 生成逻辑

`OpsEvidenceService.releaseApprovalRehearsal(...)` 先生成 v77 boundary receipt，再生成 v78 production prerequisite receipt：

```java
rehearsalManagedAuditProductionAdapterPrerequisiteReceipt(managedAuditAdapterBoundaryReceipt)
```

关键 ready 条件是：

```java
sourceReceiptAccepted =
    boundaryReceiptVersion == java-release-approval-rehearsal-managed-audit-adapter-boundary-receipt.v1
    && readyForNodeV215DryRunAdapterCandidate
    && !nodeV215MayConnectManagedAudit
    && !nodeV215MayCreateApprovalDecision
    && !nodeV215MayWriteApprovalLedger
    && !nodeV215MayPersistApprovalRecord
    && !nodeV215MayExecuteSql
    && !nodeV215MayTriggerDeployment
    && !nodeV215MayTriggerRollback
    && !nodeV215MayExecuteRestore
    && !javaApprovalDecisionCreated
    && !javaApprovalLedgerWritten
    && !javaApprovalRecordPersisted
    && !javaManagedAuditWriteExecuted
    && !nodeMayTreatAsProductionAuditRecord;

readyForNodeV217ProductionHardeningReadinessGate = sourceReceiptAccepted;
```

没有完整 header 时，它会带上：

```text
NODE_V217_SOURCE_MANAGED_AUDIT_ADAPTER_BOUNDARY_RECEIPT_NOT_READY
```

传入完整 header 后，`readyForNodeV217ProductionHardeningReadinessGate=true`，但 `javaCreatesApprovalDecision`、`javaWritesApprovalLedger`、`javaExecutesSql`、`nodeV217MayConnectManagedAudit` 等字段仍然保持 `false`。
