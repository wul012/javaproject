# v73 运行调试说明

## 版本目标

本版按最新计划 `D:\nodeproj\orderops-node\docs\plans\v203-post-ci-artifact-retention-roadmap.md` 推进 Java v73：为 `/api/v1/ops/release-approval-rehearsal` 增加只读 `liveReadinessHint`，回显 Node v204 preflight 和 Node v205 runtime smoke session 的上下文，使后续 Node v205 可以把 Java health 与 release rehearsal 纳入真实只读 HTTP smoke。

## 主要改动

- `ReleaseApprovalRehearsalResponse` 新增 `liveReadinessHint`。
- `OpsOverviewController` 为 release approval rehearsal 新增 5 个可选 `x-orderops-runtime-*` header。
- `OpsEvidenceService` 新增 `rehearsalLiveReadinessHint(...)`，并把 schema 升级到 `java-release-approval-rehearsal-response-schema.v7`。
- `verificationHint` 新增 `liveReadinessEchoWarnings`、`liveReadinessHint` schema field 和 runtime smoke 边界 proof claim。
- 单元测试和 HTTP 集成测试覆盖缺省 header、完整 header、warning digest 稳定性和 no-ledger-write 边界。
- README 与代码讲解文档补充 v73 说明。

## 关键边界

- Java 不启动 Node v205 smoke。
- Java 不记录 Node PID，不替 Node 做 cleanup 证据。
- Java 不创建 approval decision，不写 approval ledger。
- Java 不触发订单写入、失败事件 replay、deployment、rollback 或 rollback SQL。
- `runtimeSmokeExecutedByJava=false`，`javaStartedProcessForNode=false`，`nodeMayTreatAsProductionAuthorization=false`。
