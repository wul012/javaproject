# v75 运行调试说明

## 版本目标

本版按最新计划 `D:\nodeproj\orderops-node\docs\plans\v209-managed-audit-dry-run-roadmap.md` 推进 Java v75：为 `/api/v1/ops/release-approval-rehearsal` 增加只读 `approvalRecordHandoffHint`，标注哪些审批上下文字段可以进入 Node v211 managed audit dry-run packet 的 approval record 区域。

## 主要改动

- `ReleaseApprovalRehearsalResponse` 新增 `approvalRecordHandoffHint`。
- `OpsOverviewController` 为 release approval rehearsal 新增 5 个可选 `x-orderops-approval-*` header。
- `OpsEvidenceService` 新增 `rehearsalApprovalRecordHandoffHint(...)`，并把 schema 升级到 `java-release-approval-rehearsal-response-schema.v9`。
- `verificationHint` 新增 `approvalRecordHandoffEchoWarnings`、`approvalRecordHandoffHint` schema field 和 approval-record no-write proof claim。
- 单元测试和 HTTP 集成测试覆盖缺省 header、完整 header、warning digest 稳定性和 no-ledger/no-approval-record-persist 边界。
- README 与代码讲解文档补充 v75 说明。

## 关键边界

- Java 不创建 approval decision。
- Java 不写 approval ledger。
- Java 不持久化 approval record。
- Java 不做生产身份认证。
- Java 不连接生产 approval store。
- Java 不触发订单写入、失败事件 replay、deployment、rollback 或 rollback SQL。
- `nodeMayUseAsAuditApprovalInput=true` 只表示 Node 可把这些字段作为 dry-run audit approval 输入。
- `nodeMayTreatAsProductionApprovalRecord=false` 明确说明这不是生产审批记录。
