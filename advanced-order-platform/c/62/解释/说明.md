# 开发运行调试 v62：release handoff checklist fixture

## 本版目标

按最新计划 `v173-post-release-window-readiness-roadmap.md` 推进 Java v62：补 Java 发布前人工 handoff checklist fixture，供后续 Node v175 release handoff readiness review 只读消费。

本版同时融合轻量质量优化：把 ops evidence 中重复维护的静态 contract endpoint 列表收口到 helper，减少后续新增 fixture 时漏改 health/read-only/release/bundle/evidence 列表的风险。

## 改动范围

- 新增动态 evidence 字段 `releaseHandoffChecklistFixture`。
- 新增静态 contract：`/contracts/release-handoff-checklist.fixture.json`。
- 将新 fixture 接入 release verification manifest、release bundle manifest、deployment rollback evidence、rollback approval handoff、production deployment runbook、ops read-only evidence、field guide。
- 将静态 contract endpoint 列表收口到 `staticContractEndpoints(boolean includeFieldGuide)` 和 `staticContractProbeEndpoints(boolean includeFieldGuide)`。
- 补充 `OpsEvidenceServiceTests` 与 `OpsOverviewIntegrationTests`，验证动态字段、静态 endpoint 和只读边界。
- 补充 README 与代码讲解记录。

## 关键边界

```text
nodeMayConsume=true
nodeMayTriggerDeployment=false
nodeMayTriggerRollback=false
deploymentExecutionAllowed=false
rollbackSqlExecutionAllowed=false
requiresProductionDatabase=false
requiresProductionSecrets=false
connectsMiniKv=false
```

本版不执行 Java deployment，不执行 rollback，不执行 rollback SQL，不连接生产数据库，不读取 secret value，也不把 mini-kv 接入订单一致性链路。

## 计划对齐

最新计划要求 Java v62 做 release handoff checklist fixture，记录 release operator、rollback approver、artifact target、migration direction 和 secret source confirmation，并明确不执行部署或回滚。本版已按该范围完成，没有扩大到真实发布、真实回滚或生产环境配置。
