# v81 运行说明

## 1. 版本目标

Java v81 按 Node 最新计划 `docs/plans/v221-post-local-adapter-candidate-roadmap.md` 推进，在 `/api/v1/ops/release-approval-rehearsal` 上新增 `managedAuditExternalAdapterMigrationGuardReceipt`。

它承接 Node v222 `managed audit local adapter candidate verification report`，给 Node v223 external adapter connection readiness review 提供 Java 侧只读 migration / credential guard：

```text
Node v222 local adapter candidate verification report
 -> Java v81 external adapter migration guard receipt
 -> Node v223 external adapter connection readiness review
```

本版不是真实外部 managed audit adapter connection，不读取生产 credential，不执行 schema migration SQL，不写 Java approval ledger 或 managed audit store。

## 2. 新增字段

`ReleaseApprovalRehearsalResponse` 顶层新增：

```java
RehearsalManagedAuditExternalAdapterMigrationGuardReceipt managedAuditExternalAdapterMigrationGuardReceipt
```

核心字段：

```text
sourceImplementationGuard*
 -> 来源是 Java v80 managed audit adapter implementation guard receipt，source schema 固定为 v14

consumedByNodeVerificationReport*
 -> 固定 Node v222 verification report 的版本、profile、endpoint 和 ready 状态

nextNodeReview*
 -> 指向 Node v223 external adapter connection readiness review

guardDigest
 -> 对 Node v222 read-only report、owner/schema/credential review 要求、Java no-credential/no-connection/no-SQL 字段生成稳定 sha256 digest

readyForNodeV223ExternalAdapterConnectionReadinessReview
 -> 仅表示 Node v223 可以消费 guard 后做 readiness review，不代表可以连接生产审计
```

没有完整 Node v210 approval binding header 时，上游 v80 receipt 不 ready，因此 v81 guard 也不 ready，并返回：

```text
NODE_V223_SOURCE_IMPLEMENTATION_GUARD_RECEIPT_NOT_READY
```

传入完整 header 后，`readyForNodeV223ExternalAdapterConnectionReadinessReview=true`，但仍只允许 Node v223 做 readiness review，不读取生产 credential，不连接真实外部 managed audit。
