# v56 开发运行调试说明

## 版本目标

本版依据 `D:\nodeproj\orderops-node\docs\plans\v163-post-rollback-readiness-roadmap.md` 推进 Java v56：增加 release bundle manifest，把 jar、静态 contracts、release verification manifest、deployment rollback evidence 和验证证据来源收成一份只读发布包清单。

本版只做 Java 项目内部的只读 bundle evidence，不接生产数据库，不执行回滚，不改变订单交易语义。

## 代码改动

- `OpsEvidenceResponse` 增加 `ReleaseBundle` record。
- `OpsEvidenceService` 增加 `java-release-bundle-manifest.v1` 常量、`releaseBundle()` 和 `staticContractEndpoints()`。
- 动态 `/api/v1/ops/evidence` 增加 `releaseBundle` 字段。
- 新增 `src/main/resources/static/contracts/release-bundle-manifest.sample.json`。
- 更新 `ops-read-only-evidence.sample.json`、`ops-evidence-field-guide.sample.json`、`deployment-rollback-evidence.sample.json` 和 `release-verification-manifest.sample.json`，把 release bundle manifest 纳入只读证据链。
- 更新 `README.md` 记录 v56 的 bundle manifest 用途。

## 关键边界

- `bundleMode=READ_ONLY_RELEASE_BUNDLE`：只读清单，不执行发布。
- `nodeMayExecuteBuild=false`：Node 可消费 bundle，但不能替 Java 执行 Maven。
- `nodeMayTriggerRollback=false`：Node 不能触发 Java rollback。
- `requiresProductionDatabase=false`：不需要生产库。
- `changesOrderTransactionSemantics=false`：不改变订单创建、幂等、支付、库存、Outbox 或 replay 语义。
