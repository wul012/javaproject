## 主要改动

- `ReleaseApprovalRehearsalResponse` 新增 `auditPersistenceHandoffHint`。
- `OpsOverviewController` 为 release approval rehearsal 新增 5 个可选 `x-orderops-managed-audit-*` header。
- `OpsEvidenceService` 新增 `rehearsalAuditPersistenceHandoffHint(...)`，并把 schema 升级到 `java-release-approval-rehearsal-response-schema.v8`。
- `verificationHint` 新增 `auditPersistenceHandoffEchoWarnings`、`auditPersistenceHandoffHint` schema field 和 managed-audit no-write proof claim。
- 单元测试和 HTTP 集成测试覆盖缺省 header、完整 header、warning digest 稳定性和 no-ledger/no-managed-audit-write 边界。
- README 与代码讲解文档补充 v74 说明。

## 关键边界

- Java 不创建 approval decision。
- Java 不写 approval ledger。
- Java 不写 managed audit store。
- Java 不连接外部生产审计系统。
- Java 不触发订单写入、失败事件 replay、deployment、rollback 或 rollback SQL。
- `nodeMayUseAsManagedAuditInput=true` 只表示 Node 可把这些字段作为 dry-run 输入。
- `nodeMayTreatAsProductionAuditRecord=false` 明确说明这不是生产审计记录。
