# Java v94 说明：OpsEvidenceService dispatch table refactor

## 计划依据

本轮依据用户给出的 Java v94 质量优化项：

```text
OpsEvidenceService 改 dispatch table 模式
收益：主类停止增长
风险：中
```

当前 Node 计划仍要求 Java 侧继续避免把新逻辑堆回 `OpsEvidenceService`。本版是契约不变的主类瘦身。

## 合理性判断

合理。`OpsEvidenceService` 的大段重复主要集中在 release/static evidence 构建方法上，这些内容：

```text
字段固定
互相独立
不依赖数据库或运行时状态
天然适合用 registry / dispatch table 管理
```

所以这次没有改业务语义，也没有拆高风险的 release approval receipt 链，而是先抽静态证据分发表。
