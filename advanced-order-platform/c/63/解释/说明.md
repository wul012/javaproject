# 开发运行调试 v63：release audit retention fixture

## 本版目标

按最新计划 `v176-post-ci-evidence-hardening-roadmap.md` 推进 Java v63：补 Java 发布证据保留 fixture，供后续 Node v178 cross-project evidence retention gate 只读消费。

本版同时融合轻量质量优化：把 release audit retention 的读取端点和保留产物拆成 `releaseAuditRetentionEndpoints()` 与 `releaseAuditRetentionArtifacts()`，避免后续 retention gate 同时维护两类清单时混在一起。

- 新增动态 evidence 字段 `releaseAuditRetentionFixture`。
- 新增静态 contract：`/contracts/release-audit-retention.fixture.json`。
- 将新 fixture 接入 release verification manifest、release bundle manifest、deployment rollback evidence、release handoff checklist、rollback approval handoff、production deployment runbook、ops read-only evidence、field guide。
- 补充 `OpsEvidenceServiceTests` 与 `OpsOverviewIntegrationTests`，验证动态字段、静态 endpoint、retention days、audit export 字段和只读边界。
- 补充 README 与代码讲解记录。
