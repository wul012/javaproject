# v77 运行调试说明

## 版本目标

本版按最新计划 `D:\nodeproj\orderops-node\docs\plans\v213-post-restore-drill-plan-roadmap.md` 推进 Java v77：为 `/api/v1/ops/release-approval-rehearsal` 增加只读 `managedAuditAdapterBoundaryReceipt`，标注 Node v215 managed audit dry-run adapter candidate 只能消费 Java 只读 evidence 并写本地 `.tmp` 或受控测试文件，不能连接真实 managed audit，不能创建 approval decision，不能写 approval ledger，不能持久化 approval record，不能执行 Java SQL、部署、回滚或 restore。

## 主要改动

- `ReleaseApprovalRehearsalResponse` 新增 `managedAuditAdapterBoundaryReceipt`。
- `OpsEvidenceService` 新增 `rehearsalManagedAuditAdapterBoundaryReceipt(...)`，并把 schema 升级到 `java-release-approval-rehearsal-response-schema.v11`。
- receipt 固定回显 Node v214 archive verification profile、state、endpoint，以及 Node v215 candidate version/profile。
- receipt 明确 `nodeV215MayConsume=true`、`nodeV215MayWriteLocalDryRunFiles=true`，但所有真实上游写入、审计连接、审批、ledger、SQL、部署、回滚、restore 字段均为 `false`。
- `verificationHint` 新增 receipt schema field、warning digest input 和 no-ledger/no-production-audit proof claim。
- 单元测试和 HTTP 集成测试覆盖缺省 header、完整 header、warning digest 稳定性、Node v215 ready receipt 和所有 no-write/no-production 边界。
- README 与代码讲解文档补充 v77 说明。

## 关键边界

- Java 不创建 approval decision。
- Java 不写 approval ledger。
- Java 不持久化 approval record。
- Java 不写 managed audit store。
- Java 不连接真实 managed audit 或外部 audit system。
- Java 不执行 SQL。
- Java 不触发 deployment。
- Java 不触发 rollback。
- Java 不执行 restore。
- Java 不读取生产 secret。
- Node v215 只能写本地 `.tmp` 或受控测试文件。
- `readyForNodeV215DryRunAdapterCandidate=true` 不代表生产 audit/window/operations 授权。
