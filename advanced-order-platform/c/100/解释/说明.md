# Java v100 说明：CI bootstrap + large-file guard

## 计划依据

本轮依据最新有效全局计划：

```text
D:\nodeproj\orderops-node\docs\plans\v245-post-sandbox-precheck-roadmap.md
```

计划要求 Java v100 做：

```text
CI bootstrap + large-file guard
补 .github/workflows Maven compile/test 基线
把 ReleaseApprovalRehearsalResponse.java / OpsEvidenceService.java 的后续拆分目标写入 Java 自己的版本归档
不改业务语义
不写 ledger
不执行 SQL
```

## 合理性判断

合理。Java 已连续完成 v98/v99 的 managed-audit sandbox evidence 回显，但 Java 仓库自身此前没有 GitHub Actions 基线。此时继续推进真实连接不合适，先补 CI 和大文件拆分 guard，更符合当前质量优化批次。

本版不改 Java 业务代码、不新增 release approval 字段、不改变 response schema，也不触碰真实 managed audit connection。

## 本版目标

新增 GitHub Actions workflow：

```text
D:\javaproj\.github\workflows\maven-ci.yml
```

仓库根目录是 `D:\javaproj`，workflow 通过 `working-directory: advanced-order-platform` 进入 Maven 项目。

CI 内容：

```text
Java 21
Maven dependency cache
mvn -B -q -DskipTests compile
non-Docker regression tests
mvn -B -q -DskipTests package
```

首版 CI 明确排除需要 Docker/Testcontainers 的测试：

```text
PostgresMigrationIntegrationTests
RabbitMqNotificationConsumerIntegrationTests
RabbitMqNotificationFailureIntegrationTests
RabbitMqOutboxPublisherIntegrationTests
```

这些测试仍保留本地 Docker 验证入口，不作为 v100 bootstrap 的必跑条件。

## Large-file guard

当前只读观察：

```text
OpsEvidenceService.java: 656
ReleaseApprovalRehearsalResponse.java: 1343
ReleaseApprovalVerificationHintBuilder.java: 605
OpsEvidenceServiceTests.java: 3712
OpsOverviewIntegrationTests.java: 3978
```

后续拆分目标：

```text
1. ReleaseApprovalRehearsalResponse.java
   将 managed-audit sandbox receipt records 按语义拆到独立 response model 文件，保留 JSON 字段名和 record 访问器兼容。

2. OpsEvidenceService.java
   继续保持入口/常量/dispatch 角色，避免重新承载 receipt 构建逻辑；后续优先把 Node version/profile 常量按 managed-audit stage 分组。

3. OpsEvidenceServiceTests.java
   把 release approval rehearsal 大型断言拆成 focused assertion helpers 或按 receipt 分组的测试类，减少单文件继续膨胀。

4. OpsOverviewIntegrationTests.java
   后续按 endpoint/contract family 分组拆集成测试，避免新增 receipt 时继续扩大单个 integration test 文件。
```

## 本版边界

本版没有做：

```text
release approval response 字段变更
managed audit sandbox connection
credential value 读取
approval ledger 写入
schema migration SQL
Java / mini-kv / external audit service auto-start
```
