# v55 开发运行调试说明

## 版本目标

本版依据 `D:\nodeproj\orderops-node\docs\plans\v161-post-controlled-idempotency-drill-roadmap.md` 推进 Java v55：增加 deployment rollback evidence sample，说明 Java 包、运行配置、数据库迁移和静态契约的回退边界。

本版保持小而完整的工作量：只补只读证据和契约，不连接生产数据库，不启动 Docker，不改订单、库存、支付、Outbox 或失败事件 replay 的交易语义。

## 代码改动

- `OpsEvidenceResponse` 增加 `DeploymentRollback` record，并挂到 `/api/v1/ops/evidence` 顶层响应。
- `OpsEvidenceService` 增加 `java-deployment-rollback-evidence.v1` 常量和 `deploymentRollback()` 组装逻辑。
- 新增 `src/main/resources/static/contracts/deployment-rollback-evidence.sample.json`，静态说明包回退、配置回退、数据库迁移回退、静态契约回退边界。
- 更新 `ops-read-only-evidence.sample.json`、`ops-evidence-field-guide.sample.json`、`release-verification-manifest.sample.json`，把新端点纳入只读证据、字段说明和发布验证清单。
- 更新 `README.md`，记录 v55 起的部署回退证据样本用途和禁止动作。

## 关键边界

- `nodeMayTriggerRollback=false`：Node 可读证据，但不能触发 Java 回退。
- `databaseMigrationRollbackAutomatic=false`：数据库迁移回退必须由操作员确认，样本不执行 SQL。
- `requiresProductionDatabase=false`：本证据不需要也不连接生产库。
- `changesOrderTransactionSemantics=false`：不改变订单创建、幂等、支付、库存、Outbox 或 replay 语义。
