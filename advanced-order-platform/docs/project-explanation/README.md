# Project explanation index

This directory holds durable, reader-facing explanations of the Java project.
These files are not temporary scratch notes. They are kept in the repository so
new maintainers can understand the platform's value, inputs, outputs, and
operational evidence model before reading the implementation.

| File | Scope |
| --- | --- |
| `project-value-and-flow.md` | Plain-language overview of the order platform's value, transaction flow, state machine, Outbox mechanism, failed-event governance, and read-only ops evidence layer. |
